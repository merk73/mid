# Статический архив THE MIDGAS

Главная сразу открывает клиентов; аномалии и инциденты находятся в отдельных вкладках. На мобильных экранах две колонки, на компьютере шесть. Карточка содержит квадратное изображение, номер, название и характеристики. Фирменный PT Mono сохранён; логотипом служит надпись THE MIDGAS без дополнительного знака.

После каталога: интерактивные связи, карта локаций и глоссарий. Поиск, категории, теги, сортировка и фильтры работают в браузере. Фотографии доступны в полном размере, тексты и исследовательские материалы — на страницах досье.

Угроза и доступ клиента показаны цветными шкалами из пяти делений. Каждая шкала дополнена названием, числом и текстовой оценкой; отсутствующие значения отмечены как «Нет данных».

В **Настройки → Версия сайта** можно выбрать научный архив или старую версию. Выбор сохраняется на устройстве и применяется к навигации и прямым ссылкам на досье. Переключение доступно в обе стороны, в том числе с экрана входа старого сайта. Старая версия сохранена в `web/legacy/` со своими исходными скриптами, стилями, разделами и прежним подключением Supabase. Общие медиафайлы и фирменные шрифты используются из существующего каталога ресурсов.

## Статус

Это предварительная версия на снимке репозитория: 30 досье и 39 терминов. Актуальный экспорт Supabase ещё не получен. Теги и новые материалы из базы пока не сверены. У одной записи отсутствует исходная обложка, поэтому показана явная заглушка. До полной сверки рабочий сайт не заменяется. Проверка перед публикацией блокирует неполную миграцию.

Страницы новой версии не обращаются к Supabase; сохранённая старая версия использует прежнее подключение. Обложки хранятся локально без изменения оригиналов. Подложка карты загружается из CARTO/OpenStreetMap; координаты и список локаций остаются доступны при отсутствии подложки.

## Локальный просмотр

```sh
python3 -m http.server 43129 --bind 127.0.0.1 --directory web
```

Откройте `http://127.0.0.1:43129/`.

```sh
node scripts/verify-static-archive.mjs
node scripts/audit-static-site.mjs
python3 tools/static-archive-browser-smoke.py
```

Браузерная проверка требует Python Playwright и Chromium. Старые адреса реестров и короткие ссылки на досье поддерживаются. Исходные данные и серверный код сохранены для сверки.
